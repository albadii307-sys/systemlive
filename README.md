# نظامي — حياتك بنظام

تطبيق ويب عربي (RTL) لإدارة العادات والمهام والأهداف، ومتابعة النوم، والتذكيرات، والتقويم، وسجل النشاط — بواجهة داكنة متجاوبة تعمل على الحاسب والجوال.

يعمل التطبيق بالكامل داخل المتصفح، ويحفظ البيانات محليًا في **IndexedDB** مع بديل تلقائي إلى **localStorage** عند تعذر فتح قاعدة البيانات. لا يوجد خادم ولا إرسال لأي بيانات إلى الإنترنت.

---

## التشغيل

### الطريقة الأسهل
افتح `index.html` مباشرة في المتصفح. تعمل الوظائف الأساسية وحفظ البيانات، لكن **Service Worker وإشعارات النظام** يحتاجان إلى خادم HTTP/HTTPS.

### الطريقة الموصى بها (كل الميزات)
من داخل مجلد المشروع شغّل خادمًا محليًا بسيطًا، ثم افتح العنوان في المتصفح:

```powershell
# باستخدام Python إن كان مثبتًا
python -m http.server 8080

# أو باستخدام Node.js
npx serve .
```

ثم افتح: `http://localhost:8080`

> لا تحتاج إلى تثبيت حزم أو بناء المشروع. الملفات ثابتة وجاهزة.

## المميزات

### الرئيسية
- تاريخ اليوم والترحيب حسب الوقت (بتوقيت **آسيا/مسقط**).
- نسبة إنجاز اليوم، عادات اليوم، مهام اليوم، التذكيرات القادمة.
- ملخص النوم، الأهداف النشطة، وآخر عمليات سجل النشاط.
- إحصاءات آخر 7 أيام، وتحديث تلقائي بعد أي عملية.

### العادات
- إنشاء وتعديل وحذف العادة مع الاسم والوصف واللون.
- أيام التنفيذ الأسبوعية والهدف الأسبوعي.
- تسجيل الإنجاز اليومي دون فقدان السجل عند التعديل.
- الالتزام الأسبوعي، السلسلة الحالية، ونسبة الالتزام.
- تقويم إنجاز مصغّر لكل عادة.

### المهام
- أولويات: منخفضة، متوسطة، عالية، عاجلة.
- حالات: جديدة، قيد التنفيذ، منجزة، مؤجلة.
- تاريخ ووقت الاستحقاق، التصنيف، خطوات فرعية.
- ربط المهمة بهدف، وإنشاء تذكير مرتبط بها.
- تمييز المتأخرة والقادمة، وبحث وتصفية.

### الأهداف
- العنوان والوصف وتاريخ البداية والنهاية.
- القيمة المستهدفة والحالية والوحدة ونسبة التقدم.
- المراحل (Milestones) مع الإنجاز.
- سجل تقدم زمني، وربط المهام بالهدف.
- تحديث التقدم يدويًا مع ملاحظة اختيارية.

### التقويم
- عرض شهري، أسبوعي، ويومي مع تنقل وزر «اليوم».
- أحداث مشتقة مباشرة من المصدر (لا نسخ ولا تكرار):
  - المهام حسب تاريخ الاستحقاق.
  - التذكيرات موزعة حسب التكرار داخل المدى المعروض.
  - النوم: بداية النوم والاستيقاظ، والقيلولة حدث واحد.
  - العادات: فقط عند وجود سجل إنجاز.
- ألوان مختلفة لكل نوع، وتصفية حسب النوع.
- نافذة تفاصيل اليوم مع إضافة/تعديل/حذف العناصر.

### النوم
- تسجيل وقت النوم والاستيقاظ مع حساب المدة تلقائيًا، بما يشمل عبور منتصف الليل.
- القيلولة كسجل مستقل.
- ملاحظات لكل سجل، وتعديل وحذف.
- متوسط يومي/أسبوعي/شهري، أفضل يوم، الانتظام، والمقارنة بهدف النوم.
- رسم بياني لآخر 7 أو 30 يومًا، وهدف نوم قابل للتعديل.

### التذكيرات
- العنوان والوصف والتاريخ والوقت.
- التكرار: مرة واحدة، يومي، أسبوعي، شهري، أيام محددة، أو كل عدد أيام.
- ربط اختياري بمهمة أو عادة أو هدف.
- إكمال، تأجيل، إيقاف مؤقت، واستئناف.
- قوائم القادمة والسابقة، وطلب إذن إشعارات المتصفح.

### سجل النشاط
- تسجيل تلقائي لكل العمليات المهمة (إضافة، تعديل، حذف، إكمال، تأجيل...).
- يحتفظ باسم العنصر وتاريخه ووقته ومعرّفه والبيانات القديمة/الجديدة.
- يبقى السجل حتى بعد حذف العنصر الأصلي.
- بحث وتصفية حسب الإجراء ونوع العنصر والفترة الزمنية.
- نافذة تفاصيل تعرض البيانات قبل وبعد.
- تصدير سجل النشاط كملف JSON.

### الإعدادات والنسخ الاحتياطي
- الاسم وهدف النوم.
- تصدير نسخة احتياطية كاملة بصيغة JSON.
- استيراد بوضعين: **دمج** أو **استبدال**، مع تأكيد قبل الاستبدال.
- عرض حالة التخزين وحجم البيانات التقريبي.
- مسح كل البيانات بعد تأكيد صريح.

## البيانات والتخزين

### مخازن IndexedDB
| المخزن | المحتوى |
|---|---|
| `habits` | العادات وإعداداتها |
| `habit_logs` | سجلات إنجاز العادات اليومية |
| `tasks` | المهام وخطواتها الفرعية |
| `goals` | الأهداف وقيم التقدم |
| `goal_milestones` | مراحل الأهداف |
| `sleep_records` | سجلات النوم والقيلولة |
| `reminders` | التذكيرات وقواعد التكرار |
| `activity_logs` | سجل النشاط المستقل |
| `settings` | إعدادات التطبيق |

- لكل عنصر معرّف فريد (`id`) ووقت إنشاء وتحديث (`createdAt`, `updatedAt`).
- العلاقات تُحفظ بمعرّفات (`goalId`, `taskId`, `linkType` + `linkId`) وليست بنسخ من البيانات.
- توجد فهارس للتواريخ والحالات والعلاقات لتسريع القراءة.
- يتم فتح قاعدة البيانات بإصدار ومخطط واضحين، مع معالجة للأخطاء والتحويل التلقائي إلى `localStorage`.
- بنية البيانات مناسبة للمزامنة السحابية مستقبلًا (معرّفات ثابتة + طوابع زمنية)، لكن **لا توجد مزامنة سحابية أو خادم في هذا الإصدار**.

### المنطقة الزمنية
كل التواريخ الظاهرة والتعاملات اليومية تستخدم **Asia/Muscat (UTC+04:00)**:
- التواريخ اليومية تُحفظ بصيغة `YYYY-MM-DD`.
- أوقات النوم والتذكيرات تُحفظ كوقت جداري (تاريخ + `HH:mm`) لتفادي انزياح المنطقة الزمنية.
- طوابير النشاط تُحفظ كأرقام زمنية (epoch milliseconds) وتُعرض بتوقيت مسقط.

### النسخ الاحتياطي
- زر «نسخة احتياطية» في الشريط الجانبي أو الإعدادات ينزّل ملف JSON يحتوي كل المخازن والإصدار.
- الاستيراد يتحقق من الملف، ثم يطلب اختيار الدمج أو الاستبدال.
- **الاستبدال لا يمكن التراجع عنه**؛ صدّر نسخة قبل الاستيراد.
- حذف عنصر لا يحذف سجل النشاط المرتبط به، لكنه يفك ارتباط التذكيرات والمهام التابعة حسب النوع.

## الإشعارات — الحدود الحالية

الإشعارات تعمل عبر **Web Notifications** أثناء فتح التطبيق في تبويب (أو نافذة PWA) مفتوح:
- يفحص التطبيق التذكيرات كل 30 ثانية.
- عند اقتراب الموعد يظهر إشعار نظام (إن مُنح الإذن) وتنبيه داخل التطبيق.
- زر «إشعار تجريبي» في الإعدادات للتأكد من عمل الإذن.

**مهم:** إشعارات التذكيرات بعد إغلاق المتصفح بالكامل **لا تعمل** بهذا الإصدار. تحقيقها يتطلب:
1. خادم Web Push مع مفاتيح VAPID.
2. تسجيل اشتراك Push وحفظه في الخادم.
3. جدولة الإرسال من الخادم ولو كان التطبيق مغلقًا.

ملف `sw.js` يحتوي على معالجات `push` و`notificationclick` كبنية جاهزة، لكنه **لا يرسل إشعارات بنفسه** ولا يوجد خادم مرفق. هذا الحد موضّح أيضًا داخل شاشة التذكيرات والإعدادات.

## هيكل المشروع

```
index.html              الواجهة الرئيسية وترتيب تحميل السكربتات
manifest.webmanifest    بيانات تثبيت التطبيق (PWA)
sw.js                   Service Worker: تخزين مؤقت + إشعارات push اختيارية
assets/icon.svg         أيقونة التطبيق
css/styles.css          نظام التصميم الداكن العربي RTL
js/utils.js             التواريخ والمنطقة الزمنية والتنسيق والأيقونات
js/db.js                IndexedDB، المخطط، البديل، النسخ والاستيراد
js/store.js             الحالة المركزية وكل عمليات CRUD والمنطق
js/views.js             الرئيسية، العادات، المهام، الأهداف
js/views-extra.js       التقويم، النوم، التذكيرات، النشاط، الإعدادات
js/modals.js            كل النماذج والنوافذ التفصيلية
js/app.js               التنقل والأحداث والنماذج والإشعارات والتهيئة
```

تعتمد الملفات على سكربتات عادية (بدون وحدات ES) لتعمل حتى عند فتح الملف مباشرة، مع تحميلها بالترتيب في `index.html`.

## ملاحظات

- لا يستخدم التطبيق `prompt()` أو `confirm()`؛ كل التأكيدات نوافذ داخلية.
- الحذف يطلب تأكيدًا صريحًا ويستخدم معرّف العنصر الصحيح.
- لا توجد إحصاءات وهمية؛ كل الأرقام محسوبة من البيانات المخزنة فعليًا.
- لحماية بياناتك: صدّر نسخة احتياطية دورية، خصوصًا قبل مسح بيانات المتصفح أو تغيير الجهاز.
- وضع التصفح الخاص (Incognito) قد يمسح IndexedDB عند إغلاق النافذة.
